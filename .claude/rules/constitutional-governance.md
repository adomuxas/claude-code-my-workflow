# Constitutional Governance: Baltic GDP Reconstruction Paper

**These articles are immutable.** They represent non-negotiable constraints on how this project is managed. To amend an article, explicitly state "amending Article X permanently" — otherwise any override is treated as a one-time exception.

---

## Article I: Primary Artifact

The LaTeX article in `Paper/` is the **single source of truth** for all content.

- All figures and tables displayed in the paper must have source files in `Figures/`, `Tables/`, or `scripts/R/`
- No figure or table may appear in the paper without a corresponding source file
- The `Bibliography_base.bib` file is authoritative for all citations

*Rationale: Publication requires full reproducibility. A referee or coauthor must be able to regenerate every output from source files.*

---

## Article II: Plan-First Threshold

Enter plan mode for any task that meets one or more of the following criteria:

- Modifies more than 2 files
- Rewrites or restructures a paper section
- Changes the GDP reconstruction methodology or data pipeline
- Adds, removes, or substantially modifies a figure or table
- Involves decisions about data sources or estimation choices

Simple fixes (typos, formatting, bibliography entries, single-line R edits) may skip planning.

*Rationale: Methodological decisions in a reconstruction paper are interdependent. Changing one series affects all comparisons. Plan first prevents cascading errors.*

---

## Article III: Quality Gate

Nothing is committed below 80/100. Nothing is submitted below 90/100.

| Score | Gate | Meaning |
|-------|------|---------|
| 80 | Commit | Clean enough to save |
| 90 | Submission draft | Ready for co-author / advisor review |
| 95 | Excellence | Journal-ready |

Score components for this paper:
- XeLaTeX compilation failure: −100 (blocking)
- Undefined citation: −15 per instance
- Missing figure/table source file: −20 per instance
- Overfull hbox (>5pt): −5 per instance
- Unhedged causal claim (flagged by domain-reviewer): −10 per instance

*Rationale: Substantive errors in a GDP reconstruction compound. Gatekeeping ensures each committed draft is defensible.*

---

## Article IV: Reproducibility Standard

Every figure and table in the paper must be fully reproducible:

`Data/ (Excel) → scripts/R/ (code) → Figures/ or Tables/ (output) → Paper/ (included)`

- R scripts must use relative paths only (no hardcoded machine paths)
- R scripts must set `set.seed()` for any stochastic operations
- Excel source files must be committed to `Data/` (no external-only data)
- Figures must be generated at publication resolution (PDF preferred, 300 dpi minimum for raster)

*Rationale: GDP reconstruction papers are often scrutinized for data transparency. Full reproducibility is non-negotiable for credibility.*

---

## Article V: File Organization

All project files belong in one of the following canonical locations:

| Location | Contents |
|----------|----------|
| `Paper/` | LaTeX article source (`.tex`, `.bbl`, `.aux`) |
| `Data/` | Raw and processed data files (Excel, CSV) |
| `Figures/` | All figures included in the paper (PDF, PNG) |
| `Tables/` | LaTeX table files generated by R (`.tex`) |
| `Preambles/` | LaTeX preamble and style files |
| `scripts/R/` | All R scripts for figures and tables |
| `Bibliography_base.bib` | All bibliography entries (root level) |
| `master_supporting_docs/` | Reference materials, dissertation chapters (read-only) |
| `master_supporting_docs/source_papers/` | PDFs of papers cited / used for analysis (read-only) |
| `master_supporting_docs/template_papers/` | Example papers used as structural/style templates (read-only) |
| `explorations/` | Sandbox work (never included in paper) |
| `quality_reports/` | Plans, session logs, substance reviews |

Files must not accumulate at the root level. Build artifacts (`.aux`, `.log`, `.synctex.gz`) are gitignored.

*Rationale: Clean organization is essential for long-running projects. A future coauthor or the author's future self must be able to navigate the repo without explanation.*
